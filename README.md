# BetterBlueprints / 更好的蓝图

Mindustry mod that turns the blueprint browser into a tile-based gallery: tiles with configurable size and cover previews first, then click into each blueprint. Every blueprint belongs to exactly one tile.

把蓝图浏览器改造成磁贴式浏览：打开先见可配置大小与封面的磁贴，点进去看蓝图；每个蓝图只属于一个磁贴。

## Features

- Tile-based blueprint browser with configurable tile size and cover previews
- One blueprint per tile

## Requirements

- Mindustry v154+
- Java mod support enabled

## Build

```powershell
./gradlew build
```

The built jar is written to `build/libs/`.

## Usage

Open the blueprint browser (`V` in-game or from the editor) to see the tile-based gallery.

Install the mod jar through Mindustry's `Mods` menu (`Mods > Import Mod > From File`).
